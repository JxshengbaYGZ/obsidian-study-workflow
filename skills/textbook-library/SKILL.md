# 教材库整理

这是「教材一侧」。服务的学习场景是：考研按章回查原文与例题，期末按考点找结论与插图，做题时确认公式的原始条件——所以产出必须是能回原书核对的结构：正文逐块带物理页锚点，插图带图号图题，知识点单独成卡，与知识库一侧的笔记卡、题卡用「教材对照」互相回链。索引与链接由程序生成，原书 PDF 不进库。

## 执行

需要完整流程、数据格式与目录约定时，先读 [流程与格式](references/pipeline.md)；需要判断页码与图版是否可信时读 [真值与门禁](references/truth-and-gates.md)。

1. **先定口径**：确定物理页与印刷页的换算、分卷编号方式与输出目录，写进书入口和台账。之后所有页码只用物理页。
2. **转写**：先取普通文字、公式、表格或图、跨页难例各 5 页，比较本地提取与全量模型流程的质量和费用；区分可靠文字层与难页，缓存分卷块序列。丢弃装饰图与页边噪声；识别串行、标题错位不改结构，串进正文的图题按原书页面回读补回。
3. **对齐**：用 IDF 加权 4-gram 得分加单调动态规划求块→页映射。评估用重合度中位数与留一法，不用锚点命中率自证。
4. **生成底稿**：每个块前加 `<!-- 来源块：<tag>-p####-b### -->` 锚点；图片输出嵌入，图题输出斜体一行；每页段末尾插页脚表，标注刚结束的那一页。
5. **图版**：按版面裁切保存；图归给其后的第一个图题，空图题组按借用规则补一次；再用模板匹配全量确认每张图的真实页，据此改文件名、页边界与元数据。
6. **知识点卡**：按概念或原书小标题拆，不按页拆；跨页正文与必要图放在同一处。卡片简明，完整转写仍留在章级底稿；末尾来源表写节号与物理页区间。必要图复用底稿图文件，公式与表格保留为可编辑文字。
7. **索引与互链**：生成书内索引、入口与库总览；卡片直接指向正文的具体小节或来源块，并从正文对应位置回链卡片。与已有笔记在知识点级双向回链，只连能互相印证的条目，找不到专节就标「未定位专节」。
8. **门禁与安装**：机械检查、页标签核验、公式渲染、卡片覆盖、安装逐字节比对全部通过才发布。安装覆盖复制、只增不删；改名后手工删旧文件。安装前整树备份。

## 复核已有教材库

先跑 [结构检查](scripts/check_textbook_library.py) 找出悬空引用、孤儿图、页脚错位与索引缺项；再按 [真值与门禁](references/truth-and-gates.md) 判断页码是否可信。文字层图题行不可作为判据，用插图模板匹配。

## 边界

- 只声明实际做过的事：机械检查通过不等于内容正确，公式可解析不等于推导正确。
- 页码归属可以有独立判据，语义正确性没有；缺人工终审就明说。
- 体量上限内的省略（例题推导、次要枝节、考纲外内容）要在台账里写明，不让读者以为已收录。
