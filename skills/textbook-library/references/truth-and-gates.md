# 教材库的真值与门禁

| 检查 | 可证明 | 不能证明 |
|---|---|---|
| 文件和链接解析 | 目标存在、别名和路径可达 | 链接两端真是同一个概念 |
| PDF 文本相似度 | 候选页可能正确 | OCR 字词和公式正确 |
| 图像模板匹配 | 局部图可能属于某页 | 图意、子图号与图题都正确 |
| 数学语法渲染 | 表达式可解析 | 推导成立 |
| 原页抽查 | 已查样本可信 | 全书逐字正确 |
| 独立复核 | 指定条目经另一判据检查 | 未列入范围的条目也正确 |

页码与图版可以程序辅助，但要有不依赖原生成规则的第二判据。图题文字层会把正文引用误判成图题；图页归属也可能相差一页。对疑点回看原 PDF，记录原页、判断依据和待补证内容。原书印刷错误与 OCR 错误分别标识。

发布前检查：来源文件哈希、页码口径、正文块覆盖、图片存在与引用、索引与双向链、公式语法、专业抽查、备份与读回。检查失败只修受影响文件，重新执行相关门禁。静态检查不能替代 Obsidian 客户端目视。
