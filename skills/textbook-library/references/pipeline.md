# 教材库的目录与格式

每本书用一个独立工作目录，暂存区与正式库分开。正式产物示例：

```text
<学校教材>/<课程>/<书名>/
  阅读入口.md
  正文底稿/<章>.md
  知识点/<概念>.md
  图解/<页号>-<图号>.png
  与课程笔记对照.md
```

阅读入口只给章节与知识入口。版本、页数、页码换算和校对状态记后台；正文按章连续阅读，不插“PDF页”标题、页脚表或扉页占位说明。公式、表格与必要图形保留，知识卡写定义、条件和方法。

教材卡链接正文具体小节及课程笔记，课程笔记回链教材卡。无对应专节的笔记列未定位清单。索引和模板可由脚本生成，人工只处理源内容与专业判断。发布前备份、读回；改名后的旧链接与旧文件需单独迁移，不靠覆盖复制自动解决。

具体步骤见 `docs/textbook-library.md` 与 `docs/school-course-workflow.md`。这里的占位目录不代表某个用户的实际路径。
