# 学习知识库整理

版本：2026-11-09。开始笔记任务前先读[统一准则](references/note-standard.md)，再按需读专项说明。本文及统一准则替代旧的固定栏目、强制短例与自测要求；用户当前明确要求优先。

## 必须把握的取舍

- 先读现用库、相关来源与有效样稿，核实路径、章节和任务范围。更新规则不自动授权改写课程；讲解与改稿分清。
- 重写保全有效定义、条件、推导、来源原题、图表和辨析；简洁是去重，不是删成摘要。无实质改进的内容保留。
- 新概念先讲是什么、为何需要，再使用术语和公式。同类内容优先逐对象讲完整，最后横向比较；共性不重复，差异不省略。
- 基础和常见情形先讲通；首次建模与关键推理详写，重复代数略写。公式旁交代变量、口径、适用条件和选法理由。
- 不新增自编例题、练习、自测或答案，不以短例凑栏目。保留或链接来源原题；仅用户另行明确要求出题时例外。
- 知识标题无装饰序号；并列性质等在标题下逐条换行，用普通 Markdown 无序列表缩进。连续推导用自然段，不用裸 Tab 或空格对齐波形。
- 来源与整理过程记后台，影响结论的条件和限制留正文。图先看再留删；保留关键标注和读图解释，库内附件使用可移植链接。
- 复核逐项覆盖约定范围，结构扫描、原页原图、专业审读、可读性通读和客户端显示分别记录。修正局部问题后检查相关位置，不能用抽样冒充全量。
- 多文件修改先备份并维护一份库外 TaskList。写前核对当前版本，写后回读；公开发布只含通用方法，文件同步不等于运行会话已加载。
