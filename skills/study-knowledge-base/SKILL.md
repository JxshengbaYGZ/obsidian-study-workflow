# 知识库整理

打开卡片就能学到知识。默认只写定义、条件、方法、必要推导与算例；按内容决定结构，不凑栏目。

## 成品标准

- 知识卡直接进入知识；题卡保留完整题干、解答与必要方法。自编题简标“自编”。
- 标题按真实包含关系分级：页面或章用一级，节用二级，小节用三级，其下分类用四级；同级内容用同级标题，不把父标题和分项全部写成二级。短提示可用加粗，不凑标题。
- 含公式的表格使用Markdown表格与单元格内数学语法，不把LaTeX塞进HTML表格。交付前实际渲染；排版可见不等于公式正确，错符号、错位和识别异常须回原图核对。
- 来源、教材名、PDF页码、时间戳、核对范围、处理状态放后台记录，默认不在正文或属性区展示。用户要求回源时再提供。
- 有用的辨析直接写成知识结论，不挂“旧卡辨析”“编辑补充”等标签。缺条件、符号歧义、未实测等影响使用的问题，保留一句具体限制。
- 文字已完整且无额外图形的截图不展示；电路、波形等裁出完整小图。图注只补图外条件，不复述图中文字，不自动附整页或“图中结构”表。
- 一份题干、一份权威解答。只保留有用的练习与关联链接，不重复列导航或同一目标，不写“本卡依据……”等套话。

## 执行

1. 用户说“检查、复查、查一下”时，默认检查整个知识库，包括知识卡、题卡、题解、教材正文、目录和索引；只有用户明确限定范围才缩小。先盘点全部文件，将原始材料与后台记录另列，不能以抽样或只查某个文件夹代替全查。批量清理先备份。
2. 先核知识和题意，再压缩。保留条件、单位、例题数据与关键步骤；原题有缺损就说明，不猜补。
3. 按具体冗余类型处理。关键词仅筛候选，不能据此批量删含知识的句子。去掉来源备注时提取夹带的有效条件；裁图必须核看边界。
4. 检查全部改动的公式、代码、图片、表格、链接与残句；确认未出现空栏目或重复入口。修复后读回，再按已有授权同步。

少量修改不用建立复杂批次。长任务只维护一份库外进度和改动记录；报告简短说明改了什么、验证范围和未决问题。结构检查、内容审读、图形核对和客户端验收分别计数，不能把抽样说成全量。

## 按需工具

- 写卡片：[简洁模板](references/project-setup.md)。
- 恢复长任务：[执行约定](references/execution.md)；记录字段见[记录与检查](references/records-and-quality.md)。
- 需要冻结输入、版本审查和可恢复发布时，才用[批处理脚本](references/portable-workflow.md)。默认不自动展示来源；必要局部图通过 `display_source_ids` 指定。
- 需要把现有知识卡与题库用于主动练习时，按[可回源练习与掌握判定](../../docs/grounded-practice-loop.md)记录首次独立作答、具体错因和复做结果；只把经核定的知识修订回写权威卡。
- 有专业争议时读[审查规则](references/review.md)；需要交接时读[分工](references/model-routing.md)。
