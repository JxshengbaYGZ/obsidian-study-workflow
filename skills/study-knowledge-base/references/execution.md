# 执行约定

## 开始

核对实际目录、已有文件和用户指定范围。先审查现状，再决定删改；简单清理不强制新建项目或重跑整套批处理。

## 整理

1. 按知识概念组织，不按来源页拆卡。先弄清条件和图形，再压缩文字。
2. 知识卡只留定义、方法、成立条件、必要推导和算例。题干与解答各留一份；已有例题就链接复用。
3. 来源文件、页码、时间戳、处理状态和复核证据记在库外；不重复放进卡片属性与正文。原件归档，来源信息可按需查询。
4. 纯文字已转写就不再展示截图。确需图形时裁完整局部，核对标注、方向、坐标与选项；不重复描述图中文字。
5. 有用的辨析融入正文；无用说明删除。条件不足、歧义和未验证边界必须具体说明，不能删成无条件结论。

## 验收与接力

批量修改先备份，按文件记改动。对全部改动检查公式、代码、附件和跳转；含知识的删改逐项审读，裁图逐图检查。关键词扫描只产生候选。

长任务维护一份进度：目标、完成范围、未决问题、下一步。交接带实际路径和必要证据，不复制全部历史。无需在每题重复检查表。

作者自检、独立专业复核、程序检查和客户端验收分别报告。没有实际完成的项目不标通过；不以材料模糊为由猜造题干或实测数据。
