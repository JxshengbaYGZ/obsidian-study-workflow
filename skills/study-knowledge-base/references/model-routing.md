# 按风险分工，不绑定模型品牌

| 工作 | 合适的执行者 | 升级触发 |
| --- | --- | --- |
| 文件清单、链接、缺图与统计 | 确定性程序 | 规则无法解释异常 |
| 清晰文本、候选整理、已核定内容排版 | 通过样例试做的经济模型 | 条件缺失或来源冲突 |
| OCR 争议、证明、独立解题 | 对应能力经过验证的模型 | 证据仍不足则请求材料 |
| 最终复核 | 独立推导或独立审查者 | 同类错误扩散时扩大范围 |

使用任意供应商模型前记录实际版本，并用清晰材料、模糊符号、缺条件、错误答案和冲突来源试做。不要将未经试验的模型当成已经通过验证；也不要求每个任务重复使用昂贵模型。

模型自报高置信度不等于正确。实际模型以工具配置为准，无法识别则写未知。不凭文字自称判定后端，费用以用户实际服务为准。

## 接力记录

- 目标与本批范围。
- 已完成、未完成及原因。
- 文件、页码/题号或字幕时间戳。
- 原始证据、争议原文和已做验算。
- 已确认修正，防止下一轮覆盖。
- 下一步以及是否需要更清晰原稿、教材或人工判断。
- 实际执行模型/审查者，未知则注明。

先保存交接记录，再给出具体提醒。没有实际切换工具时不声称已切换；升级模型不能代替补齐来源。该工作流本身不授权上传个人资料或调用额外付费服务。
