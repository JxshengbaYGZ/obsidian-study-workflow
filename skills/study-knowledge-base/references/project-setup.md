# 简洁模板

沿用已有目录与格式；以下栏目按需使用，短卡可以只有标题和正文。

标题层级按包含关系确定。例如教材用 `# 第2章` → `## 2.1` → `### 2.1.1` → `#### 1）分类`。不能让父子标题同级；只调整层级时保留标题文字，避免破坏跳转。

公式表用Markdown表格，公式写在单元格的 `$...$` 中，绝对值用 `\lvert...\rvert` 避免拆列。不要在HTML表格里混写LaTeX；必须保留曲线、合并布局等图形信息时，可用清晰局部表图，不同时重复转写。

## 知识卡

```markdown
# 概念名称
定义、公式及成立条件。

## 方法
必要步骤与使用边界。

## 例子
能说明问题的短例。
```

有帮助才加练习或关联链接。默认不附教材名、来源页码、整理状态，也不建立空栏目。

## 题卡

```markdown
# 题意标题
完整条件、问题与选项。

> [!example]- 解答
> 关键推导与结果。

必要的方法提醒。
```

题解也可按已有习惯分文件保存，避免两处重复正文。自编题在标题简标“自编”；不伪造原题图。只有题意依赖图形时嵌入局部图，图注仅写图外必要信息。

## 后台记录

来源、页码、原件和改动证据放私有记录或批次清单。正文只保留影响理解与使用的具体疑点、条件和未验证边界。
