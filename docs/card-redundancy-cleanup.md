# 图文去冗余

先审内容，再决定删、裁或保留。判断以信息是否必要为准。

| 情况 | 处理 |
| --- | --- |
| 文字、公式、表格已完整转写，截图没有额外信息 | 删除截图展示 |
| 依赖电路、波形、受力、几何或结构 | 裁完整局部图，核对边缘、标注及选项 |
| 同一整页用于多卡 | 按题判断；需图的裁图，其余不展示整页 |
| 已有图，又有“图中结构”等逐字描述 | 删除复述，只补图外必要条件 |
| 来源、教材、页码、核对状态、整理身份 | 记后台，默认不展示于卡片或属性 |
| 缺条件、符号歧义、未实测 | 留一句具体限制，不包装成确定答案 |

## 批量清理

1. 固定完整范围并备份，列出实际文件。
2. 扫描模板与共用图片，生成候选；关键词和引用次数不能决定删除。
3. 阅读候选内容，提取来源备注里夹带的有效知识。先核图、裁图，再修改引用。
4. 检查全部改动的公式、代码、图片、链接、表格、空栏目和残句；图形与专业语义人工核验。
5. 保存一份后台改动记录，验收后同步。报告核验范围，不把程序检查称为全文审读。

原件归档，不需要以每卡的来源页链接证明保留。用户要求回源时再提供位置。公开示例不得带入私人材料。
