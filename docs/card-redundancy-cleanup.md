# 知识卡与题卡的图文去冗余

同一个知识点卡或题卡里，经常同时存在三样东西：已转写进正文的文字、按题裁出的整页原图、以及指向原件的链接。三者用途不同，但“整页原图”最容易变成纯冗余：文字已经完整，图里却还压着相邻题、页脚和别人的手写批注。本页给出判定与清理的规范，用于减少“图片只是重复文字”的情况，同时避免删掉题干依赖的图。

## 判定：四种处置

先判断图片在卡片里承担什么角色，再选处置方式。四档互斥，按优先级从 1 到 4 判断。

| 档位 | 判据 | 处置 | 保留下来的东西 |
|---|---|---|---|
| 1. 纯重复 | 文字、公式、算例已完整写进卡片；图里没有波形、框图、频谱、几何结构或表格结构等文字无法等价表达的信息 | 删除图片嵌入 | 来源说明、页码、可打开原件的链接 |
| 2. 图形必要 | 题干或知识点依赖图：电路、波形、受力图、几何示意、曲线、表格结构 | 从原页裁局部图，配一句“图中：…”说明 | 局部图、图注、题号与选项文字 |
| 3. 整页跨卡共用 | 同一张试卷页/手写整页被多张卡重复嵌入 | 各卡删嵌入，统一改为原件链接（带页锚点） | 来源身份说明、“原卷含原作答与批注”这类边界说明 |
| 4. 来源身份 | 说明这张卡依据的页码、转写范围、未核对项、刻意保留整页的理由 | 保留，只做措辞中性化 | 来源短语、页码口径、已知限制 |

判断顺序很重要：先确认“文字是否真的完整”，再问“图是否携带额外信息”，最后才决定“裁局部还是留整页”。跳过第一步就会删掉尚未转写的公式或条件。

## 可脚本化的部分

以下步骤可以写成一次性脚本批量执行；脚本不必进仓库，方法进文档即可。

| 检查 | 判据 | 产出 |
|---|---|---|
| 全库普查 | 扫描全部 Markdown，统计每卡的图片嵌入数与来源页引用（如“课件原页/第N页”“原图/手写笔记-第N页”“原图/练习册-第N页”等命名模式） | 逐卡台账（路径、类型、图片数、来源页数、候选标记）与汇总计数 |
| 候选筛选 | 用来源页命名模式和“整页”“折叠块”等结构短语标出疑似整页图嵌入 | 候选清单，按学科分组 |
| 共用图统计 | 按图片路径聚合引用卡数量，≥2 张卡的图进入“跨卡共用”档 | 高频图清单（图 → 卡列表 + 题干摘要） |
| 题干需图初筛 | 从“完整题干/题目/原题”段提取文字，匹配“图、波形、电路、示波、曲线、输入输出”等词 | 疑似需图卡清单，作为人工优先项 |
| 批量替换 | 正则匹配旧结构（图片嵌入行、说明句、折叠块），替换为统一模板；保留 BOM 与换行符，改前按相对路径备份 | 每轮“改文件数/命中数/未匹配清单” |
| 残留复查 | 目标图片路径残留数、旧说明句残留数、局部图引用数、需图卡结构完整性 | 计数报告，逐项应为 0 或符合预期 |

替换模板要写成固定结构，避免每张卡各写一套措辞。题卡删整页图后常用：

```markdown
## 原题来源

[[原卷 PDF#page=N|查看原卷 PDF 第N页]]。原卷含相邻题与手写批注，见该 PDF 页；本题按原文转写，不据此认定作答结论。
```

知识卡删纯文字页图后，正文保留下载链接与“教材原页/课件原页”说明，不再嵌整页图。

## 必须人工判断的部分

- 文字是否完整：公式上下标、单位、表格结构、图注、题目的选项文字，脚本只统计字符，判不了语义。
- 图是否多余：波形、框图、几何结构、频谱通常文字无法等价表达，不能按“图里有文字”就删。
- 裁图边界：不能切掉题号、选项、图注、相邻小问的条件；裁剪后要放大看边缘。
- 裁图取舍：整页保留、局部图、原件链接三种处置中，只有第一档可以全自动执行。

## 操作步骤

1. 固定原件与备份。清理前把整个目标范围复制到按相对路径组织的备份目录，或整体打包；之后每一步都基于同一份备份回滚。
2. 全量普查建台账。先统计全部卡，再筛候选；不要先改再看还有多少。
3. 按四档定候选。台账里逐卡标“纯重复/图形必要/跨卡共用/来源身份”，拿不准的单独列“待人工”而不是猜。
4. 人工过一遍候选。重点看题干是否依赖图、文字是否完整、整页是否多卡共用；这一步不做批处理。
5. 先做裁图并核验。按原页渲染坐标裁，裁完用行坐标叠加框、联系表和放大图检查边界；核验不通过的图宁可整页保留。
6. 分批替换。先小批（十几张卡）跑通模板，再扩到全量；每轮记录未匹配项，多轮处理变体结构，直到未匹配为 0。
7. 复查五项。目标图残留数、局部图引用数、旧话术残留数、需图卡结构、抽样全文；结果写进记录，不说“全部正确”。
8. 记录已知限制。刻意保留的整页图数量、原因、涉及范围要写下来，下次不重复讨论。

## 案例（2026-10 批次）

- 普查 4,507 个笔记/题卡，筛出 204 个候选（其中“图文重复候选”按结构特征自动标出，绝大部分是整理过程话术，见[整理过程话术的清理](editorial-phrase-cleanup.md)）。
- 跨卡共用整页图：18 张原页被 188 张题卡引用。其中模拟电子技术 5 张选择题依赖图形，裁成选项/电路局部图（桥式整流接法、三只 BJT 饱和状态、两级反馈电路、差放电路、二极管与门钳位）；模拟电子技术另有 22 张含电路图、波形的分析计算题页图保留整页，作为已知限制；其余卡删嵌入改 PDF 页链接。
- 课件页分类：通信原理已嵌入课件的 158 页逐页查看后，83 页是纯文字/公式/算例（删嵌入），78 页含必须保留的图形（裁局部图替换，22 张知识点卡改嵌局部图）。
- 大学物理练习册 18 题：先按原页 OCR 行坐标对 18 个题框做裁图核验（含 1 题示意图单独补框）；7 题裁图形局部图，11 题无图，删除整题裁图并保留题干与来源页。
- 整页手写页：48 张知识卡（信号与系统 21、大学物理 27）把整页手写/练习册扫描图改为“查看手写原页/练习册原页”的原件链接。

## 已知限制

- 图形必要但无法可靠裁切的整页图会保留，例如题干依赖图形、但原页同时含相邻题与批注，裁图容易漏条件。这批 22 张模拟电子技术分析计算题页图即属此类。
- 裁图边界只能目视确认，脚本只能辅助对齐；抽样之外的图不算已审。
- 改原件链接后，阅读时需要一次跳转才能看到原页，这是减少重复嵌入的代价。

## 隐私边界

本页只写方法与数量的口径。真实试卷 PDF、原页截图、题卡原文、台账与修改清单不进公开仓库或按占位名处理；示例中的课程名与数字只用于说明判定规模。
