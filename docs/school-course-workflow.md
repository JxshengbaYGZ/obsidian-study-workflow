# 学校课程：教材与个人笔记怎样对应

本流程适用于一门课程逐步获得教材 PDF、转写文本、视频字幕、课件或个人笔记的情况；其中任意一种材料都可先形成概念卡，后来再按[多来源增补方法](incremental-source-completion.md)补缺。学校课程书目与考试专用书目分开管理；每本书有独立入口，课程笔记按概念组织。核教材内容以原书页图为准，自动字幕和 OCR 是待核稿。

## 建议结构

```text
学校教材/<课程>/<书名>/
  阅读入口.md                 原书版本、页码口径、核对状态
  正文底稿/<章>.md            完整可编辑转写，保留待核标记
  知识点/<概念>-教材定位.md  对应原书小节与物理页
  与课程笔记对照.md           双向映射与未定位清单

课程笔记/<课程>/
  学习路线.md                 可选；说明先修顺序与教材、练习入口
  知识点/<章节或主题>/<概念>.md  定义、条件、方法、短例、易错边界
```

目录名是示例，可以沿用现有库的命名。课程目录已说明学科，卡片名从概念开始；文件树承担按主题查卡的任务。原始字幕、临时来源清单和处理状态可以保存在知识库外的私有工作区。重复导航的收口与来源退役步骤见[课程入口与来源清理](direct-browsing-and-source-retirement.md)。

## 每批五步

1. **锁来源**：仅清点指定文件，记录版本和可回查位置；教材另记哈希、物理页数、目录、转换器及是否有文字层，课件记页，字幕记时间片。核封面署名与印刷页换算；卷首和封底不要机械套用正文页码差。
2. **分两侧**：教材侧按章保存完整底稿并标识未审范围；笔记侧按概念写清条件和可复算短例。需要先修顺序时保留一份学习路线，不复制逐卡目录，也不把口语识别错字写入权威知识卡。
3. **建立映射**：教材确有对应处时，笔记卡直达教材知识点卡和正文具体小节，教材卡回链笔记。对照表列小节与 PDF 物理页。读过字幕、课件或其他来源后，把有用解释并入相应知识卡；不能仅凭标题建立知识对应。没有教材专节的课程应用注明其前置知识，不硬造教材卡。
4. **核高风险内容**：原页查看公式、图号、表格、跨页段落和反常结论。原书自身印错时保留原文并附“编者校核”；转写串文则隔离于阅读稿，原始转写留档。远程图片未本地化时不得标“离线完整”。
5. **回读验收**：检查来源覆盖、文件与链接、数学语法，再独立复算关键结论和目视客户端。分别报告“结构通过”“抽样内容复核”“全量逐字终审”，不能互相替代。

## 常见症状与处理

| 症状 | 排查与处理 |
|---|---|
| 文件名与封面信息不同 | 以原书封面确定书卡标题；保留原件名，在记录中说明差异。 |
| OCR 混入无关句或图题打断正文 | 对照原页与前后文，保留原始输出，在阅读稿隔离或纠正，并记录页码。 |
| 视频标题含同一个词却讲不同概念 | 核对完整标题、上下文与实际讲解主题；仅在概念确实一致时建立对应关系。 |
| 课时都进入索引，笔记仍像空壳 | 标题、网址和字幕链接只完成归档。挑实际读过的片段，把有用的推导、短例和条件写进知识卡；让学习导航直接进入知识点。 |
| 已读一小段却把整课标成完成 | 私有工作记录写明已读范围、未读范围和真正融入的知识卡；全课验收另计。 |
| 来源目录遮住了知识点 | 将课时清单和原始字幕移出日常入口；如果不再需要在知识库中保留，先做可回读的私有备份，再按精确清单撤下，并修正引用。 |
| 课程导航、知识点导航和文件树重复列卡 | 按章节或主题分文件夹；只保留真正解释学习顺序与资料入口的页面，先迁入独有资源再撤下重复清单。 |
| 教材、课件或视频只来一种 | 先从这一来源做可学习的概念卡；以后新来源出现再比对条件、例题与冲突。 |
| 链接存在却仍需翻整章 | 把落点细化到具体知识点或正文小节，增加对应位置回链。 |
| 公式能显示却结论不对 | 查定义、前提、单位和短例，必要时给出反例；渲染通过只算语法证据。 |
| 在线图片断网消失或图片域名无法解析 | 从原 PDF 提取少量关键局部图，核图号、页码和图题；其他未处理的远程图单列数量和状态，不宣称整本离线完整。 |
| Markdown 表格里的 wiki 链接错列 | 表格单元格中的 `[[目标|别名]]` 需转义竖线，并实际预览。 |

## 课程专题：有成套字幕和课件时按讲次重构知识卡

当一门课同时具备按讲次排列的视频字幕、配套课件页和教材，而现有知识卡仍是按教材章节组织时，可以按“课程优先”做一轮重构。目录侧先按[以课程为主线的可顺序学习目录](course-first-learning-index.md)把讲次、课件页、卡和练习排成可顺序入口，再逐张改写知识卡：

1. **先做讲次映射**：每讲对应到它将读的知识卡、练习和课件页范围；明确标出有课件页的讲次与只有字幕的讲次，后者在卡内统一写“本讲无对应课件页，仅字幕”。
2. **逐讲改写**：卡头写“本讲时间段 + 课件页 + 考试定位”；正文按课程讲授顺序分节，每节末尾标 `（P<讲次> 时:分–时:分；课件第 N 页）`。课程口述的定义、框图、条件和方法优先；教材降为“教材辅助对照”小节，只给印页、物理页和式号，供回查。
3. **课件原页作证据**：框图、公式、例题页用整页原图核对并按需嵌入；课程例题逐题复算，自编算例标明“整理者自编”。课程、课件与教材数字冲突时分源写明（以课程口径和标准表/精确式为准），不把两套结论混成一句。
4. **保留旧来源身份**：旧的跨课程字幕增补、旧教材卡降级为“其他课程补充”，注明原来源与时间段，不删除旧证据；教材侧原有证据链继续有效。
5. **统一口径**：同一课程内的公式记号、页码换算、符号约定先写一份规范；课件查表值与精确式不符时以精确式复算为准，并在卡内标出原值和处理方式。
6. **验收分层**：静态链接与锚点检查、每章抽看一至两张卡对照字幕与课件、例题独立复算、客户端目视分别报告，未做的层级别写“已通过”。

配套检查表：讲次→卡→练习是否全部有落点；无课件页讲次是否标“仅字幕”；课程与教材冲突是否在卡内可见；卡头“学习路线、教材定位、课件原页索引”三个链接是否齐全。

## 简化与费用评估

程序做限定范围的枚举、回链和文件检查；模型只处理当前小节的解释与歧义，另一审查者集中核高风险点。固定一份小样与同一验收清单，记录各方案的真实输入/输出 token、重试、时间、费用和错误数。没有可比较的调用记录，就只写“流程简化方案”，不宣称节省金额或 token。质量下降时撤回分流规则。

## 公开边界

只能发布本页这类抽象方法及虚构示例。真实教材、字幕、笔记、路径、页码台账、特定课程的错题和工作日志留在私人库。公开前逐文件检查暂存清单、差异和历史引用。
