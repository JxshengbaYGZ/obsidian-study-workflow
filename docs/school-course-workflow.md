# 学校课程：教材与个人笔记怎样对应

本流程用于一门课程同时有教材 PDF、转写文本、视频/课堂资料和个人笔记的情况。学校课程书目与考试专用书目分开管理；每本书有独立入口，课程笔记按概念组织。原书页图是校对依据，自动字幕和 OCR 是待核稿。

## 建议结构

```text
学校教材/<课程>/<书名>/
  阅读入口.md                 原书版本、页码口径、核对状态
  正文底稿/<章>.md            完整可编辑转写，保留待核标记
  知识点/<概念>.md            对应原书小节与物理页
  与课程笔记对照.md           双向映射与未定位清单

课程笔记/<课程>/
  导航.md
  知识点/<概念>.md            定义、条件、方法、短例、易错边界
  课时入口/<课时>.md          回到原视频或字幕，不冒充已审结论
```

目录名是示例，可以沿用现有库的命名；重点是原书、课程笔记和原始字幕各有单份权威来源。

## 每批五步

1. **锁来源**：仅清点指定文件，记录哈希、版本、物理页数、目录、转换器及是否有文字层。核封面署名与印刷页换算；卷首和封底不要机械套用正文页码差。
2. **分两侧**：教材侧按章保存完整底稿并标识未审范围；笔记侧按概念写清条件和可复算短例。原视频字幕留原处，用课时卡建立入口；补一条按先修关系排列的学习路线，不把口语识别错字写入权威概念卡。
3. **建立映射**：笔记卡直达教材知识点卡和正文具体小节，教材卡回链笔记。对照表列小节与 PDF 物理页。课时卡可先按标题连“候选概念卡”，须明确标为待核；读过字幕和视频后再确认对应。只有主题确实一致才连；一对多关系写明原因，找不到专节列为未定位。
4. **核高风险内容**：原页查看公式、图号、表格、跨页段落和反常结论。原书自身印错时保留原文并附“编者校核”；转写串文则隔离于阅读稿，原始转写留档。远程图片未本地化时不得标“离线完整”。
5. **回读验收**：检查来源覆盖、文件与链接、数学语法，再独立复算关键结论和目视客户端。分别报告“结构通过”“抽样内容复核”“全量逐字终审”，不能互相替代。

## 常见症状与处理

| 症状 | 排查与处理 |
|---|---|
| 文件名与封面信息不同 | 以原书封面确定书卡标题；保留原件名，在记录中说明差异。 |
| OCR 混入无关句或图题打断正文 | 对照原页与前后文，保留原始输出，在阅读稿隔离或纠正，并记录页码。 |
| 视频标题含同一个词却讲不同概念 | 核对完整标题、上下文与实际讲解主题；仅在概念确实一致时建立对应关系。 |
| 课时都进入索引，笔记仍像空壳 | 标题、网址和字幕链接只完成归档。挑关键课时，结合字幕时间点、教材小节和可复算短例写概念卡；未处理的课时保留待核状态。 |
| 链接存在却仍需翻整章 | 把落点细化到具体知识点或正文小节，增加对应位置回链。 |
| 公式能显示却结论不对 | 查定义、前提、单位和短例，必要时给出反例；渲染通过只算语法证据。 |
| 在线图片断网消失或图片域名无法解析 | 从原 PDF 提取少量关键局部图，核图号、页码和图题；其他未处理的远程图单列数量和状态，不宣称整本离线完整。 |
| Markdown 表格里的 wiki 链接错列 | 表格单元格中的 `[[目标|别名]]` 需转义竖线，并实际预览。 |

## 简化与费用评估

程序做枚举、模板、索引、回链和文件检查；模型只处理当前小节的解释与歧义，另一审查者集中核高风险点。固定一份小样与同一验收清单，记录各方案的真实输入/输出 token、重试、时间、费用和错误数。没有可比较的调用记录，就只写“流程简化方案”，不宣称节省金额或 token。质量下降时撤回分流规则。

## 公开边界

只能发布本页这类抽象方法及虚构示例。真实教材、字幕、笔记、路径、页码台账、特定课程的错题和工作日志留在私人库。公开前逐文件检查暂存清单、差异和历史引用。
