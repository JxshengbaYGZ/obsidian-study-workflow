# 课程知识库

按知识点和先修关系组织文件夹，卡片名直接写概念。课程、教材和视频都是输入，默认不让讲次、页码和来源说明占据卡片。

1. 核对用户指定的现有资料，来源版本与读取范围记后台。
2. 阅读相关内容并检索已有卡，有新增知识才补卡；不因换了来源再建同义卡。
3. 正文按对象组织，先解释概念，再连接机制、模型、必要推导与用法；来源题目和答案各存一份，不新增自编题。
4. 课程要求、授课时间、教材对应页和核对状态不写入卡片；知识结论有差异时，写清所用模型、记号与条件。
5. 纯文字截图已转写就不展示；必要图形裁完整局部。只补图外条件，避免图片加表格加文字的三重重复。
6. 全部改动验收后同步。专业审读、图形核对、结构检查和客户端验收分别记录。

文件树能承担检索就不再列逐卡导航。学习顺序确有帮助时保留一份简短路线；按讲次建课程入口仅在用户明确需要时采用。原始字幕、页码映射和处理进度留后台。

详略按实际理解障碍分配，不强制短例或自测。短卡可以很短；复杂内容的必要步骤不能省。没有图、实验结果或完整题干就不编造。
