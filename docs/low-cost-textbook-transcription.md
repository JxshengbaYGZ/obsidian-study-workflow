# 教材转写：把模型调用留给疑难页

先用本地提取和一次 OCR/版面识别取得可缓存的原始结果，再让模型只处理看不清、错序或专业条件冲突的页面。节省请求次数是设计目标；实际 token 和费用必须测量，不能估算成既成效果。

## 小样对比

从普通文字、公式、表格/图和跨页难例各取若干页，固定同一来源和同一验收清单。两条流程都核正文完整、公式等价、图题归属、表格结构与来源页码。记录模型、输入/输出 token、缓存命中、重试、用时、费用和错误数。质量下降的分流规则撤回。

## 分流

| 页面类型 | 先做什么 | 何时升级 |
|---|---|---|
| 有可选文字且阅读顺序正常 | 提取文字、坐标和页号 | 公式、图题或跨栏顺序有歧义时 |
| 扫描页带 OCR 文字层 | 对照页图抽查文字层 | 错字、图、表或公式风险高时 |
| 纯图片页 | 本地 OCR/版面识别一次并缓存 | 局部仍无法确认时 |
| 波形、电路、几何等关键图 | 从 PDF 裁图并记录区域 | 图意或裁切边界不清时 |

缓存键至少包含源文件哈希、页号、提取器版本和参数。模板、索引、链接与来源表由程序生成；模型只编写需要理解的内容。复核只重跑改过的页和卡，原 PDF 始终是最终判断依据。

交付时分开报告文件覆盖、机械检查、抽样专业复核和逐字终审。没有真实用量台账时不宣称节费比例。
