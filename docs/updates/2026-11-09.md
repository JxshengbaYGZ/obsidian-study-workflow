# 2026-11-09 笔记工作流更新

本次统一整体约束、学习顺序、详略与呈现方式。主标准集中在[学习笔记整理准则](../../skills/study-knowledge-base/references/note-standard.md)，旧专项文档按需补充，两个技能入口采用同一口径。

| 方面 | 更新后的行为 |
| --- | --- |
| 范围与保全 | 从上下文确认完整范围，保留有效知识；规则更新不触发整库重写 |
| 学习主线 | 新概念先解释；同类对象分别讲完整，再比较；先常见情形再扩展 |
| 内容流畅度 | 交代问题、模型和推导的联系，修复理解断点，不只添加定义段落 |
| 详略 | 首次建模和关键转化详写，重复代数与重复定义略写，不设字数或栏目指标 |
| 公式用法 | 说明条件、符号口径和选法依据；比较前统一基准，不凑通用公式 |
| 题目边界 | 撤销强制短例、独立练习与自测；默认不新增自编题，来源原题按需保留 |
| 阅读排版 | 知识标题无装饰序号；并列性质分行缩进；连续推理用自然段 |
| 图形与附件 | 看图后决定留删，不用空格对齐波形；核对库内路径和接收端显示 |
| 验收与同步 | 内容、来源、可读性、渲染及发布分层记录；更新文件不等于运行会话已加载 |

软件演示与测试中的虚构材料仅用于验证工具，不是自动向用户知识库添加自编练习的授权。已有教材与题答存储布局继续沿用；本次不迁移私人资料，不改变无关权限或项目配置。

安装更新见[多 AI 同步](../multi-ai-sync.md)。用户阅读反馈仍是后续改进的依据，本规范不宣称已通过所有客户端或所有课程的实际学习验收。
