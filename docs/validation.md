# 验证范围与证据等级

## 可以自动检查的内容

仓库测试和脚本可以检查清单、文件存在、链接、图片引用、公式定界符、版本绑定、发布前冲突与回读一致性。运行测试时记录命令、退出码和实际覆盖范围；测试夹具的“approved”只是模拟状态，不能代表真实教材已经专业审查。

## 需要人或独立审查者判断的内容

- PDF 原页上的文字、公式、图、表是否与转写一致；页码归属是否正确。
- 定义与推导的前提、边界、单位和短例是否成立。
- 课程笔记与教材小节的对应是否真实，而非仅标题相似。
- Obsidian 阅读模式中的数学、表格、图片与链接是否可用。

报告按“来源清单已固定 → 结构检查 → 原页抽查 → 专业复核 → 客户端目视 → 全量终审”分别写状态。不做的阶段写“未验证”，不要把抽样、回归测试或静态检查改称全量正确。

## 2026-10-10：既有库的只读审计工具

Windows、Python 3.12 环境运行 `python -X utf8 -m unittest discover -s tests -v`，61 项测试通过；其中 11 项审计工具测试使用自编临时小库，覆盖链接、锚点、歧义、跨库边界、公式与 HTML 的误识别、输出目录限制及重解析目录不遍历。重解析目录用可控模拟验证分支，不宣称跨平台真实联接点均已实测。

该结果支持工具与现有工作流的合成用例回归；不代表任何私人笔记、原页、题解、外部网页或 Obsidian 客户端已经全量审定。运行方式与输出见 [审计工具说明](vault-audit.md)。

## 批量清理类任务的验收

整页图去冗余、整理话术清理等多文件批量修改的验收层级见[批量清理的验收](validation-batch-cleanup.md)：在静态检查之外，补清单一致性、结构断言与分层报告口径。


## 已有笔记重写的完整性与可学性

表达优化与重写还须核对原稿内容去向、标题与分类覆盖、概念递进及整卡可学性，按[重写验收清单](learning-note-rewrite.md#整卡验收避免局部补丁)逐项记录。结构检查不能替代这些判断；原有知识、有效图表不得因压缩目标被无声删除。真实掌握仍需学习者独立作答与迁移证据。
