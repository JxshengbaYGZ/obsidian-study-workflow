# 从可回源笔记到可检验的掌握

这是一条可选的学习闭环，适用于已有概念卡、原题和权威解答的知识库。它借鉴了 [DeepTutor](https://github.com/HKUDS/DeepTutor) 的来源定位、阅读与练习衔接、按主题检查掌握程度等设计；这里描述的是通用工作方法，不表示已安装或验证 DeepTutor。

## 一次练习怎样走完

1. **确定问题和来源。**从现有题目或实际问题出发，找对应概念卡，核对定义、条件和必要图形。检索命中只负责指出候选位置；关键公式、图号和题干仍对照原页或原图。若未见图像像素，不能说“已核图”。
2. **先独立作答。**遮住解答，写出所用条件、关键步骤和结果。不会时记录卡住的具体一步，再看提示或解答；不要把看懂解答计作独立做对。
3. **定位错误。**按题干识别、概念/条件、建模、推导、计算、图形读取分类；只修正有证据的权威卡或答案。缺原页、缺图或来源冲突的条目继续待核。
4. **复做并判定。**隔一次学习会话后，用同题或已有同类题无提示重做，核对答案及理由。达到预先写明的标准才标“能独立完成”；失败则回到对应知识点。若题库缺题，标明缺口，不自动把生成题当原题。
5. **回写最少信息。**概念卡保留必要结论、条件和题目入口；题卡保留完整题干及唯一权威解答。作答日期、错误类别、复做结果和来源核对范围写在私有学习记录中，不把这些过程信息重复塞进每张知识卡。

现有库若是一题一页、答案折叠，直接沿用；若题目与解答分在两页，也只需保证双向可达和权威解答唯一。学习卡可按主题放置、编号或不编号，沿用已验收的文件结构，不为套用此闭环批量重排。

## 来源图形的边界

DeepTutor 的[来源图形说明](https://github.com/HKUDS/DeepTutor/blob/main/docs-for-user/SOURCE_VISUALS.md)区分了原始图像、图注文本、检索记录和模型实际看到的图像。这一点可直接用于验收：记录材料身份、原图/原页位置、实际查看方式及尚未覆盖的图；文字检索成功不能证明图已完整提取，更不能证明图中箭头、坐标或下标读对。

## 小范围试用的验收

选一个章节和一组已有题，逐题记录：是否定位到正确来源、是否核对关键图式、首次独立作答结果、错误原因、复做结果。分别统计结构与链接、来源原页、专业解答、客户端显示的检查范围。只有真实做过的环节才标通过；静态检查和生成练习不能代替学习者的独立作答。

此处只借鉴方法。是否把 DeepTutor 接入某个实际知识库，需另外验证本机配置、来源权限、中文公式与图、引用准确性、数据落点和回写行为。
