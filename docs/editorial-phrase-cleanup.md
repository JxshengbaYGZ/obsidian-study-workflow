# 整理过程话术的清理分层

知识卡越写越多，正文里会混进两类不该长期留下的句子：一类是整理工作本身的痕迹（谁在什么时候把旧卡改成了新版、这批是否复核过），另一类是教学与考试要求的口吻（“背下来”“老师强调”“课程要求掌握”）。前者对读者没有信息量，后者把“来源怎么说”和“要求怎么背”混为一谈。清理时又不能一刀切：知识转述与来源对照必须留下，否则卡片就失去了可回查的底账。

本页给出一套三层判定：必删、慎改、保留，并给出可脚本化执行与需要人工判断的边界。

## 三条原则

- 过程留台账，正文不留过程。整理批次、旧卡改名、复核状态应当是记录文件与 frontmatter 的事，不占用正文。
- 知识陈述代替教学叙事。“本题按课程口径判”可以保留为方法说明，但“老师要求把这条背下来”改成陈述句或删除。
- 删要求，不删来源。来源、页码、转写范围、未核对项、无法辨认的位置必须能被读者看到。

## 第一层：必删

命中即删除，不需要逐句讨论；批量替换前先逐条列映射，全部人工确认后再跑。

| 类别 | 典型串 | 处理 |
|---|---|---|
| 整理者自我指涉 | “整理者补充”“整理者按”“由整理者重新推导”“（整理者自审）” | 改中性或直接删 |
| 旧卡/旧增补 | “旧卡保留”“旧增补记录过”“旧卡辨析保留”“并入旧卡内容” | 内容并入正文，过程词删 |
| 批次状态 | “本批已复核”“本批正文与自编题复核”“状态: 本批” | 改为无批次的中性状态 |
| 背诵要求 | “（必背简答题）”“课程要求背下来”“背两条：①”“不要求背” | 删要求，保留标题或知识内容 |
| 教师/课堂口吻 | “老师强调”“课上说过”“考试常考填空题” | 改成方法说明或删 |
| 模板套句 | “不是原稿逐字转写”“未完成逐字终审”“保留题干、原图和对应范围内的批注” | 删除；核对范围移到记录文件 |

替换映射要按“先长后短”排序：整句替换放在词级替换之前，否则词级替换会把整句切成无法匹配的碎片。脚本中先统一弯引号等排版差异，并跳过路径含“整理记录”的文件。

## 第二层：慎改

转述课程或教师说法时，句子里同时含知识内容和教学要求，需要逐句判断。

| 原句形态 | 建议改法 | 理由 |
|---|---|---|
| “课程说这个公式只要记结论” | “本课只要求使用结论，推导见教材” | 保留“要求范围”这一信息，去掉“记”的口吻 |
| “课程给出的是简化判据” | “常用简化判据为…（完整判据见教材）” | 知识内容不丢，来源仍可查 |
| “课程只要求广义平稳” | “这里只要求广义平稳” | 从“教学规定”改成“内容范围” |
| “考试按课程口径判” | “判定按此简化，但要知道定义边界” | 保留判卷边界，去掉备考叙事 |

判断标准只有一句：这句话删掉后，读者是否还能知道“这个内容在课程范围内怎么用”。能，就删；不能，就改成陈述句。

## 第三层：保留

- 来源身份：“本卡依据课程第 5 讲与教材 §2.5.1”“教材辅助”“课程未讲的部分按教材补”。
- 来源对照：同一结论在课程与教材中写法不同、口径不同的说明。
- 诚实限制：“原图未见本题作答”“原卷该处无法辨认”“输入源图文数值冲突，分别给出两种条件解”“独立复核: 待阶段复核”——这类话必须留，它们比“已核对”更有信息量。
- 有意的教学口径：例如“这里按课程口径判定，完整定义边界见…”，保留句中的范围限定。

## 可脚本化的部分

| 步骤 | 做法 | 输出 |
|---|---|---|
| 候选提取 | 按词表扫描全库：整理者、旧卡、旧增补、本批、背下来、必背、老师、课堂、课程要求、课程给出、课程口径等 | 命中行清单（文件 + 行号 + 上下文） |
| 分类初筛 | 命中行按关键词归入必删/慎改/保留三档 | 待人工清单，人工只需看“慎改”档 |
| 分批替换 | 每批一个脚本，规则为“文件 + 串/正则 + 新串”；保留 BOM 与换行符，改前备份，统计命中与未匹配 | 每批改文件数、替换数、未匹配清单 |
| 多轮收敛 | 每轮处理一类结构，直到未匹配为 0 | 轮次记录 |
| 全库残留 | 清理后对全库 grep 关键词（排除整理记录目录），残留数应为 0 | 残留统计 |
| 台账同步 | 修改清单与记录文件同步更新 | 可回查的修改清单 |

frontmatter 里的批次状态可机器化处理，但状态语义要人工定：`状态: 本批已复核` → `状态: 已复核`，`独立复核: 本批主控已核算` → `独立复核: 已核算`，`本批新增` → `新增`。注意“已核”“已复核”“已复核且独立复算”不是一回事，合并状态词时会丢掉复核强度，宁可保留原强度词、只去掉“本批”。

## 必须人工判断的部分

- 一句“课程说…”是知识来源，还是单纯的教学要求。前者保留并改写成来源对照，后者删除。
- 状态措辞的强度：静态检查通过、原页抽查、独立复算不能合并成一句“已复核”。
- 引用锚点：如果正文链接指向 `#整理者补充` 这类小节锚点，改名时要同步改链接与标题，否则链接断掉。
- 删除后上下文是否仍通顺：整行删除后要读一遍前后句，脚本不做语义衔接。

## 操作步骤

1. 全库提取候选，输出“命中行 + 上下文 3 行”，按学科分组。
2. 人工只判定“慎改”档；必删与保留按清单直接批处理。
3. 第一批先做 10–15 张卡试跑，检查替换后的段落是否通顺。
4. 每批执行后跑一次残留扫描，把未匹配行加入下一轮清单。
5. 多轮收敛：先句级模板、再词级自我指涉、最后 frontmatter 状态。
6. 全库残留应只剩“保留”档的合法命中；把剩余命中逐条记为允许保留并写理由。
7. 抽样通读：每类抽 3–5 张完整卡片，只看正文连贯性与来源说明是否还在。

替换后的验收按[批量清理类任务的验收](validation-batch-cleanup.md)分层报告；判断一条话术属于“知识转述”还是“教学目标”时，参考[知识卡与题卡的图文去冗余](card-redundancy-cleanup.md)里“区分候选类型”的做法。

## 案例（2026-10 批次）

- 全库普查 4,507 个笔记/题卡，标出 204 个带整理过程话术的候选。按学科分布：电磁场与电磁波 48、数字电子技术 21、通信原理 20、复变函数 19、离散数学 18、单片机 18、传感器 12、微弱信号检测 11、模拟电子技术 10、大学物理 8、信号与系统 5、线性代数 5、VHDL 3、控制工程基础 2、电路分析 2、数字化测量 1、概率论 1。
- 传感器原理 12 张卡：整行删除模板句（“正文的模型推导和数值例为补充内容，不是指定教材的逐字转写；指定第五版的原页、目录节号及习题尚未核对。”），来源行保留。
- 模拟电子技术 31 张卡：删“本卡推导与算例含补充内容…不是原稿逐字转写”一类后缀，来源说明保留。
- 通信原理 13 张卡第一批：教学叙事改知识陈述，例如“课程给的一句记忆：”改为“一句记忆：”、“（必背简答题）”从标题删除、“课程对功率谱密度的态度是定义了解即可”改为“功率谱密度的用法是给一个谱求平均功率”。
- 整理者自我指涉：多轮替换把“整理者自编/整理者补充/整理者按”等 27 条模式改为中性表述，并保留 `[[阅读边界#整理者补充]]` 这类锚点链接；随后一轮删模板句，最后一轮把 frontmatter 的“本批”前缀去掉。收敛后清理范围（Good Notes 笔记+题，4,507 个 Markdown，排除整理记录目录）的“整理者”命中为 0。
- 最后一轮只剩 4 处“本批”，其中 3 处是“本批来源/本批可用原页”改为“现有来源/现有可用原页”，1 处留在历史复盘文件；逐条确认后保留。

## 边界

本页只写判定与操作规范。真实的命中清单、修改台账、原文片段留在使用者本机，不放进公开仓库；案例中的课程名与数量用来说明规模，具体文件名、教材版本与个人记录不收录。
