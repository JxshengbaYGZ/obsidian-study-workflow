# 清理整理话术

卡片直接写知识，不讲整理过程。

| 原内容 | 处理 |
| --- | --- |
| 教材名、取自第几页、原PDF入口 | 移到后台记录 |
| “本卡依据”“已逐项核对”“独立补充”“原解答页保留内容” | 删除套话与标签 |
| “旧卡辨析” | 有效辨析融入正文，无效内容删除 |
| “老师要求背”“课程未讲，教材补充” | 删授课过程，保留实际知识 |
| 图下重复描述已可见的文字和结构 | 删除复述，仅补图外条件 |
| 缺条件、记号约定、歧义、未实测 | 具体、简短地保留 |

关键词只用于找候选；“噪声来源”“时钟来源”等本身是知识，不能删除。含公式或条件的出处备注须先提取有效内容。

修改后通读句子，检查括号、句首、公式、代码、图和链接，避免留下“的定义”“为按教材”等机械删词残句。核验记录保留后台，不用新说明替代旧说明。
