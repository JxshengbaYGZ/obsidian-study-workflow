# 从扫描教材到可校对的教材库

正文按章节和知识小节连续阅读；保留完整转写与必要图形。页码、来源和转换状态保存在后台，默认不显示“PDF页”标题、来源页脚或扉页占位说明。自动转写不因排版整齐就成为已核定原文。

## 八步流程

1. **定页码**：登记 PDF 物理页与印刷页的关系，分别处理封面、正文、书末和分卷。
2. **转写**：先看文字层；扫描页做 OCR/版面识别并保存原始输出。用小批样页比较质量和费用。
3. **对齐**：把内容块映射到物理页。若使用文本相似度或单调对齐，必须用独立页图/图版判据复核，不用生成锚点自证。
4. **生成正文**：按章保留完整可编辑文字、公式和表格；来源定位记后台。异常转写只在影响理解处简述。
5. **处理图版**：只裁有独立信息的图，核边界、图号、图题和真实页；图文放在同一阅读位置。远程图链没有本地化时注明离线缺口。
6. **做知识点卡**：按概念而非按页切分，写定义、条件、必要推导与易错点；例题和图按需要保留，不用空泛摘要冒充正文。
7. **建索引与双向链**：书内目录到具体小节，教材卡到笔记卡，笔记卡回教材卡；无对应专节时写未定位。
8. **验收发布**：先备份，按批回读。文件、公式语法、图片、页码、专业内容和客户端显示分别记录；改名、删除和旧链接迁移单独处理。

学校课程与个人笔记如何对应，见[学校课程工作流](school-course-workflow.md)。题目和其他资料的知识库整理，见[知识库流程](workflow.md)。

## 真值边界

页级文字匹配能帮助定位，但 OCR 错字可能仍在本页；图片模板匹配能帮助判断图在哪页，不解释图意；数学渲染只证明语法可解析。专业结论需要回原页并独立复算。小批抽样不能被写成全书逐字终审。
