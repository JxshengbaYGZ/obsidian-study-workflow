# 以课程为主线的可顺序学习目录

适用于同一知识库已有教材卡、视频字幕、课件和练习，但旧目录只能按主题查找、不能从头学到尾的情况。

## 来源优先级与目录职责

1. 先登记实际拥有的课程课次、字幕时间戳、课件页数和版本。目录按课程教学顺序排列，每讲给出字幕、课件定位、对应概念卡和练习入口。
2. 指定课程是主要内容来源；教材章节只作为辅助检索和查缺索引。两者章节顺序不一致时，保留课程顺序，并在辅助索引写明映射。
3. 每张现有知识卡必须在目录里有可点击入口。课程没有覆盖的教材概念进入“补充学习”，标明来源身份，不能冒充课程讲授内容。
4. 每个单元遵循“课程与课件 → 知识卡 → 独立练习 → 核对解答 → 回卡纠错”。目录应列出所有现有卡片，不只给抽象的学习建议或部分示例。

## 字幕、课件和 OCR 的约束

- 字幕自动识别可能错写术语、数字和符号。给出课次与时间戳；重要公式回到视频画面或课件原页。
- PDF 文字层乱码时先看渲染后的页面。若画面正常，可强制 OCR；OCR 结果须与原页图核对，尤其是上下标、分式、图中箭头和坐标轴。仅有可检索 Markdown 不等于公式与图已验收。
- 插图在本地笔记中保存原页定位或合法的个人引用；公开方法仓库不收录受版权保护的课件、字幕、原图或由此转写的大段正文。
- 对同一概念出现不同教材版本、符号或数值例题时，分开记载各来源的条件，复算后才合并结论。

## 完成检查

按来源清单逐讲核对是否有目录入口，按知识卡清单核对是否有入口；检查内部链接、附件与练习解答配对。目录验收与正文验收分别记账：逐卡检查内容能否支持顺序学习，逐页核对实际使用的课件图、公式和例题；未核页数与未核卡数单列。若只抽查 OCR 或卡片，只能报告抽查结果。结构完整、OCR 成功、专业内容正确、客户端可读分别报告，不把一种证据代替另一种。
