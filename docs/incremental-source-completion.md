# 从任意来源持续补全一张知识卡

教材、视频字幕、课件、习题和个人草稿可以单独启动一张概念卡；新来源到来时，再给同一张卡补它真正带来的内容。来源是证据，概念卡是学习成果。只有标题、链接和文件名的入口，不能算知识卡已经完成。

## 最小记录

每份来源在私有工作记录中保留原件位置、版本、可回查位置（教材页/节、课件页、视频时间片）、材料类型和处理状态。这份记录不必成为 Obsidian 导航页面。状态含义如下：

| 状态 | 已做的事 |
|---|---|
| 仅建索引 | 已确认材料存在，尚未读内容 |
| 已初筛片段 | 只读过标明的片段，用于决定后续主题 |
| 已融入概念卡 | 已读内容实际贡献了定义、条件、推导、例题、反例或应用，并在私有工作记录中能找到相应知识卡 |
| 关键结论已复核 | 写明用原页、独立推导、计算、画面或实验中的哪种方法核过 |

“已读片段”要写具体范围，不能自动升级为“整课已审”。课件页和教材节同理。审核者的推导或自编例题应标明身份，不能伪装成原材料中的例题。

## 每次新增材料怎么处理

1. 找到真实讲点：读该来源的相关段落及必要上下文，确认版本和术语。不能仅凭标题或目录给概念卡分配来源。
2. 找到或新建概念卡：用“对象、条件、可复算短例”确定它是否与已有卡讨论同一问题。一个来源足够清楚时即可建卡；没有教材不妨碍课程拓展卡成立。
3. 只写增量：来源带来更严格的条件、更清楚的图解、另一种算法或一个反例，就补相应段落；完全重复的说法无需进入日常知识导航。
4. 比较说法：逐项标明支持、互补、版本差异、冲突或未判定。有冲突时留下双方位置和独立判据。教材原页与自动转写相矛盾时，先判断是原书问题还是识别问题。
5. 接回链并复核：有对应原书小节时，教材定位卡与概念卡双向链接。课程独有应用不硬造教材专节。原始字幕和课时索引只在确有回看需求时加入知识库；否则留私有来源记录。最后检查链接、公式、短例和读者实际打开后的呈现。

一张可学习的概念卡至少回答：它是什么、什么条件下成立、如何手算或复现一个小例子、各来源分别贡献什么、哪里尚需证据。教材侧可保存按章可编辑正文，概念卡则聚合解释和差异；二者不互相冒充。

## 典型返工及避免方式

| 症状 | 改法 |
|---|---|
| 课时都入库，笔记仍像空壳 | 用知识卡是否能解释和复算来验收；把实读片段融入推导、短例和条件。 |
| 视频标题与实际讲点不一致 | 用实际字幕和上下文修正主题；未读部分继续标“待核”。 |
| 片段时码或文件名写错 | 从原始来源清单取文件路径，回源核对时间端点；显示名不能充当文件名。 |
| 不同课时的字幕文本完全相同 | 比较原字幕文本并记录重复关系；再核视频或导出流程，不能把两个标题都当成各自内容已消化。 |
| 原始字幕和课时入口淹没知识点 | 日常入口只留导航、学习路线和知识卡；需要撤下原始文件时，先按精确清单做可回读私有备份，再删除，复核无悬挂链接。 |
| 不同版本的章节号混用 | 每个来源记录版本；只按概念比对，不把甲版页码直接套乙版。 |
| 课程独有内容被硬配教材 | 把教材标为前置知识或“无专节”，仅给真实来源建立直接回链。 |
| 自编例题被误认作来源例题 | 标“整理者独立推导/构造”，注明哪些条件来自来源，哪些为新增假设。 |
| 自动转写与原页不一致 | 回看原页或画面，区分识别错误、原作者笔误与真实概念冲突。 |
| 每次补充都重读全套材料 | 缓存不变来源清单，只取与当前概念有关的新片段；程序检查链接，模型审语义疑点。 |

## 如何判断流程是否真的省时

用同一小批材料和同一验收清单比较两种做法，记录输入/输出 token、用时、重试、发现的错误及返工量。没有可比的真实调用记录，不声称成本已下降。若节省调用导致错误或遗漏增加，保留原来的深读步骤。

公开示例使用虚构材料；真实教材、字幕、课件、笔记及处理台账留在私有知识库。
