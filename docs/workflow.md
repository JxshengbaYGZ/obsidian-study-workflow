# 简洁知识库工作流

目标是打开就能学，正文只留知识、题目与必要图形。

1. **先全查**：默认覆盖知识卡、题卡、题解、教材正文、目录和索引；只有用户明确限定时才缩小。原始资料与后台记录也列入盘点，按用途审查，批量改动先备份。
2. **保住知识**：读清条件、单位、图形与问题，检查关键推导；不猜补缺损，不把待核变成定论。
3. **删掉冗余**：去掉教材名、页码入口、来源身份、处理状态与整理口吻；有用的辨析直接融入知识。来源信息留后台，按需查询。
4. **图文各司其职**：已完整转写的纯文字图不展示；必要的电路、波形、结构图裁出完整小图，不再附一段图中文字的复述。
5. **只存一份**：题干、解答各有权威位置；关联链接有帮助才留，同一入口不反复列。
6. **验收再同步**：逐个检查改动，保护公式、代码与图形；确认链接、表格和残句，再按授权上传。

短卡无需凑“定义—方法—例题—关联”全套栏目。长任务用一份后台进度和改动记录；普通编辑不强制冻结、独立审查和复杂发布流程。确需这些机制时用[批处理说明](../skills/study-knowledge-base/references/portable-workflow.md)。
