# 从资料到长期知识资产

这是「知识库一侧」。目标是以后能找到、理解并正确使用知识：复习阶段按考点检索，考研与期末按章推进，做题时能回查来源。使用场景以学习为主，但不裁剪知识本身来迎合暂时的任务。

教材原文一侧（扫描教材整理成可回查页码的正文与知识点卡）见[从扫描教材到可校对的教材库](textbook-library.md)；两侧用「教材对照」回链相连，页码一律用 PDF 物理页。

## 一次整理的完整流程

可执行入口见 [正式批处理协议](../skills/study-knowledge-base/references/portable-workflow.md)。配置与题干先冻结，AI 只编写正文片段，程序统一生成链接与结构；独立复核和排版证据通过后才发布。输出有版本记录，支持中断恢复和重复发布。

1. **清点来源**：登记文件、页数或时间段、材料类型及是否有解答；区分完整来源与已抽出的候选。
2. **做一个完整样例**：知识点、对应题目、标准解答、来源裁图及双向链接一起完成，再决定排版与批量大小。
3. **知识点按概念拆分**：写定义、条件、方法和有实质意义的应用；原页码仅用于追溯，不把每页硬做成一个知识点。
4. **题目独立存放**：题干和选项完整文字化，保留对应原题与原作答截图。没有原作答就如实说明；自编题标清来源身份。
5. **先核原题，再解题**：独立求解后比较已有答案；检查定义域、前提、边界、单位和反例。来源缺陷不静默改写，可解修订另列。
6. **让关联可理解**：链接旁说明“这是使用前提”“这题练习该方法”等关系，不堆内部题号。
7. **技巧单独提炼**：记录具体动作、适用条件、失效边界、可复算短例和原文位置；概念复述或重复片段无需强建技巧卡。
8. **分层复核并发布**：机械检查文件和链接；语义检查推理；原图检查转写；同步所有展示及生成数据，保留未解决项。

## 用知识库回答新问题

1. 从问题中的对象、已知条件和目标检索知识点、方法与旧题；先确认笔记的适用条件和证据状态。
2. 独立作答并核对关键推导或实验结果。引用旧题时保留来源位置，不能把旧答案的正确性当作本题的证明。
3. 回看此次用到的权威笔记：有错误或缺口就修正，有新边界就补充；保留必要定义、条件、例子和证据后再删重复句。没有实质改进就不改文件。
4. 同步受影响的题卡、解答和导航，并记录改动原因与验证范围。待补证内容继续明确标记，不因表达变短而消失。

## 大型现有库的结构调整

将题目和推导分为两个互相链接的页面：题目页保留完整题干、原图、来源与状态，解答页保存推导、方法和必要图示。知识点里的重复例题正文改为短摘要和入口，权威解答只留一份。按读者的常见问题与学科章节建立导航，别让用户必须先猜出术语才能找到概念；导航覆盖数不等于内容验收率。

大批量改动后分别检查：所有计划项是否有去向，题目与解答链接是否可达，图与公式是否能显示，以及抽取的专业内容是否真的正确。结构脚本与页面预览能发现遗漏和排版问题；旧题语义正确性仍需按来源复核。需要公开案例时使用虚构材料和可复现测试，个人库的复盘留在私有位置。

## 模型怎样接力

让程序做清单和链接检查，让经济模型做清晰材料整理，让推理与识别能力经过验证的模型处理争议、证明和独立解题。是否升级取决于错误类型与验证结果，不由品牌或价格直接决定。

换模型前保存目标、已完成范围、疑点、来源位置、验算和下一步。不能实际切换时明确提醒用户；其他可独立完成的工作继续。更强模型不能保证恢复被遮住的内容。

## 怎样判断是否有用

主解应适合当前学习顺序：优先使用材料章节内、前置知识较少且运算合理的方法。更高级的技巧只有在前提说明充分时使用；另一种解法可折叠补充。标准解答不仅要算对，还要让读者能解释关键一步为什么成立。

经济模型的执行细则见 [Terra自检与阶段复核](../skills/study-knowledge-base/references/terra-review.md)：固定样例与JSON结构、原图像素坐标、裁图边界、主解选择和批末验收集中维护，避免在每题重复长检查表。当前目标是让Terra中等思考自主完成清晰常规材料；模糊来源和无法验证的推导单独保留，不承诺全学科零错误。

学习时，遮住答案重新做题并解释成立条件；工作中，将实际问题的变量、单位、假设、验证数据与相关知识连接起来。资料整理完成不等于知识已掌握，公式正确也不等于工程模型已经验证。

## 完成报告

分别列出审查过的知识点、题目、技巧、原图页及字幕范围；说明修正、待补证、未审查数量。链接或公式语法检查通过，不写成“全部内容正确”。
